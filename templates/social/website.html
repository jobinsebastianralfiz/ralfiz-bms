Connect Google Analytics and Search Console

This page shows {{ site_label }}'s visitors, contact-form leads and Google searches. It reads them with a Google Cloud service account, a read-only robot login, so no Google app review is needed.

  1. Google Cloud console → your project → IAM & Admin → Service accounts → Create (name: ralfiz-website-reader, no roles needed) → open it → Keys → Add key → JSON.
  2. Enable Google Analytics Data API and Google Search Console API under APIs & Services → Library.
  3. Google Analytics → Admin → Property access management → add the service account's email as Viewer. Note the Property ID (Admin → Property details, a number).
  4. Search Console → {{ site_label }} → Settings → Users and permissions → Add user → the same email, Restricted.
  5. Railway (ralfiz-bms): GOOGLE_SERVICE_ACCOUNT_JSON = the key file's contents, WEBSITE_GA4_PROPERTY_ID = the number, WEBSITE_SEARCH_CONSOLE_SITE = sc-domain:ralfiz.com (or https://ralfiz.com/ for a URL-prefix property).
