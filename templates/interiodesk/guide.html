Step 1

Installation

Download and install InterioDesk on your macOS or Windows computer. The setup takes less than a minute.

laptop_mac

macOS

macOS 11 Big Sur or later
  1. Download the InterioDesk.dmg installer file from the link provided to you.
  2. Double-click the .dmg file to mount it. A window will appear with the app icon.
  3. Drag the InterioDesk icon into the Applications folder.
  4. Open Applications and double-click InterioDesk to launch. If prompted, click "Open" to allow the app.
desktop_windows

Windows

Windows 10 or later (64-bit)
  1. Download the InterioDesk_Setup.exe installer file from the link provided to you.
  2. Double-click the installer. If SmartScreen warns you, click "More info" then "Run anyway".
  3. Follow the installation wizard — choose your install location and click Install.
  4. Once installed, launch InterioDesk from the Desktop shortcut or Start Menu.

Pro Tips

Get the Most Out of InterioDesk

Quick tips to help you work faster and smarter.

backup
Regular Backups

Go to Settings → Backup & Restore to create regular backups. Your data is stored locally, so backups are essential.

search
Global Search

Use the search bar on the dashboard to quickly find any customer, project, invoice, or quotation across all modules.

receipt_long
PDF Branding

Upload your company logo and header image in Settings → Company to get professional branded PDFs for all documents.

calendar_today
Financial Year

Set your financial year start month in Settings → Company. All document numbers will automatically follow the FY format.

link
Linked Workflow

Project → Quotation → Work Order → Invoice. Each step links to the previous, keeping everything connected.

auto_awesome
Auto Expenses

Salary payments, petty cash debits, and supplier payments automatically create expense entries — no double entry needed.
