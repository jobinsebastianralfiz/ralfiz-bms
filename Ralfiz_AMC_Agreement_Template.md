## 4. SCOPE OF SERVICES

Ralfiz shall provide the following services for the Covered System during the AMC Period:

### 4.1 Corrective Maintenance
- Identification and fixing of bugs and defects in the Covered System.
- Fixing issues caused by errors in code delivered by Ralfiz.

### 4.2 Preventive Maintenance
- Periodic health checks of application and server performance.
- Monitoring of logs, errors and uptime (where monitoring access is available).
- Database optimisation and clean-up as required.

### 4.3 Adaptive Maintenance
- Updates required due to changes in OS versions (Android / iOS), browser updates, or mandatory third-party API changes, limited to keeping **existing features** working.
- Updating framework and package dependencies for security and compatibility.
- Resubmission of mobile app builds to Google Play Store / Apple App Store when required for compliance (client developer account required).

### 4.4 Security & Backup
- Application of security patches and SSL renewal support.
- Periodic database backups as per **Schedule B** (where hosting is managed by Ralfiz).
- Restoration support from available backups in case of data loss.

### 4.5 Technical Support
- Support via [WhatsApp / Email / Phone / Ticketing Portal] during Support Hours.
- Remote assistance for usage-related queries.
- Minor content updates (text, images, banners) up to **[X] hours per month**.

### 4.6 Minor Changes Allowance
- Small modifications (e.g., label changes, minor UI tweaks, simple report field additions) up to **[X] hours per month / [X] hours per year**. Unused hours **do not** carry forward.
