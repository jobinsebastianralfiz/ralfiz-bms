Introduction & setup

What Python is, why companies use it, and how to write and run your first program.

What is Python?

Python is a high-level, general-purpose programming language created by Guido van Rossum and first released in 1991. It's known for readable code: it uses indentation instead of curly braces, and its syntax reads close to English.

Where Python is used
  • Web backends: Django, FastAPI, Flask
  • Data analysis & AI: pandas, NumPy, PyTorch
  • Automation & scripting: reports, file processing
  • APIs for mobile apps (Flutter, React Native)
  • DevOps, testing, scraping, IoT
Key characteristics
  • Interpreted: runs line by line, with no separate compile step
  • Dynamically typed: you don't declare variable types
  • Batteries included: a huge standard library
  • Multi-paradigm: procedural, OOP and functional
  • Indentation matters: 4 spaces define code blocks

Lesson 12 · Functions · 75 min

Functions

Package logic into named, reusable, testable blocks. This is the most important habit in programming.

Defining and calling functions

print vs returnprint shows something on screen. return hands a value back to the caller so it can be used: stored, calculated with, or tested. Business functions should return values.

Returning multiple values

*args, **kwargs and keyword-only arguments

Mutable default argument trapdef add(item, cart=[]) reuses the same list on every call. Use cart=None, then if cart is None: cart = [] inside the function.

Scope: where variables live (LEGB)

Python looks up names in this order: Local → Enclosing function → Global (module) → Built-in.

Avoid global stateFunctions that read and change global variables are hard to test and debug. Pass values in as arguments and return results.

Writing good functions

  • One job per function. If you need "and" to describe it, split it.
  • Verb names: calculate_total, send_invoice, is_valid_phone.
  • Short: usually under 20–30 lines.
  • Return values; don't print inside business logic.
  • Validate inputs early and raise clear errors (Lesson 16).

Clean code checklist (PEP 8 and beyond)

Style
  • 4-space indentation, lines ≤ 88–100 characters
  • snake_case functions and variables, PascalCase classes, UPPER_CASE constants
  • Imports at the top: standard library, then third-party, then your own
  • Let tools format for you: ruff format or black, plus ruff check
Design
  • Small functions with one job; return values instead of printing
  • No magic numbers: GST_RATE = 18
  • Handle specific exceptions; never use a bare except
  • Secrets in environment variables, never in code or Git
  • Write tests for every business rule

Python interview questions

The questions most often asked of junior Python developers. Answer each one aloud before opening it.

1. List vs tuple: what's the difference?

Lists are mutable and tuples are immutable. Tuples are hashable (if their contents are), so they can be dict keys, and they're slightly faster and lighter. Use tuples for fixed records and lists for collections that change.

2. What are mutable and immutable types? Give examples.

Mutable objects can change in place: list, dict, set and most class instances. Immutable ones can't: int, float, str, tuple, frozenset, bytes. "Changing" an immutable creates a new object.

3. is vs ==?

== compares values; is checks whether two names point to the same object. Use is only for None, True and False.

4. Explain the mutable default argument problem.

Default values are evaluated once, when the function is defined. A list default is shared across all calls. Use None and create the list inside the function.

5. What are *args and **kwargs?

*args collects extra positional arguments into a tuple; **kwargs collects extra keyword arguments into a dict. Used in calls, * and ** unpack sequences and dicts into arguments.

6. What is a list comprehension? When shouldn't you use one?

A concise way to build a list: [x*2 for x in nums if x > 0]. Avoid it when the logic is complex, nested deeply, or has side effects. Use a loop for readability.

7. What is a generator? Why use one?

A function that uses yield to produce values lazily, one at a time. It saves memory with large or infinite data and allows streaming pipelines.

8. What is a decorator?

A function that takes a function and returns a new function that adds behaviour (logging, timing, auth, caching) without changing the original code. @deco is shorthand for f = deco(f). Use functools.wraps to keep the original metadata.

9. Shallow copy vs deep copy?

A shallow copy creates a new outer container but shares the inner objects. A deep copy (copy.deepcopy) recursively copies everything, so nested changes don't leak between the copies.

10. What is self? What does __init__ do?

self is the instance a method is called on, passed automatically. __init__ initialises a new instance's attributes after it's created.

11. @staticmethod vs @classmethod?

A classmethod receives the class (cls) and is often used for alternative constructors. A staticmethod receives neither the instance nor the class. It's a utility function grouped inside the class.

12. What is inheritance? What is the MRO?

Inheritance lets a class reuse and extend another class's behaviour. The MRO (Method Resolution Order) is the order Python searches classes for a method in multiple inheritance (C3 linearisation). See it with Class.__mro__.

13. What are dunder (magic) methods?

Special methods like __str__, __len__, __eq__ and __add__ that let objects work with built-in functions and operators.

14. Explain try / except / else / finally.

try holds code that might fail; except handles specific errors; else runs if no error occurred; finally always runs, for cleanup.

15. What is the GIL?

The Global Interpreter Lock in standard CPython allows only one thread to execute Python bytecode at a time. Threads still help I/O-bound work; use multiprocessing for CPU-bound work.

16. How is memory managed in Python?

Mainly reference counting: an object is freed when no references remain. A cyclic garbage collector cleans up reference cycles.

17. What does if __name__ == "__main__": do?

That code runs only when the file is executed directly, not when it's imported as a module.

18. Why use a virtual environment?

To isolate each project's dependencies and versions, so projects don't conflict, and to reproduce the setup with requirements.txt.

19. Why not use float for money?

Floats are binary approximations (0.1 + 0.2 != 0.3). Use Decimal, created from strings, with explicit rounding.

20. What is SQL injection and how do you prevent it?

An attack where user input changes the meaning of a SQL query. Prevent it with parameterised queries (? or %s placeholders) or an ORM. Never build SQL with string formatting.

21. Explain with statements.

They use context managers (__enter__ and __exit__) to guarantee setup and cleanup, such as closing a file or committing or rolling back a transaction, even when errors occur.

22. Difference between append and extend?

append(x) adds x as one item (even if x is a list); extend(iterable) adds each element of the iterable.

23. How do you remove duplicates from a list while keeping order?

list(dict.fromkeys(items)). Dicts keep insertion order and their keys are unique.

24. What are lambda functions?

Small anonymous one-expression functions, typically used as a key for sorting or with map and filter: sorted(users, key=lambda u: u["age"]).

25. What's new in modern Python (3.10–3.13) that you've used?

Examples: the match statement (3.10), X | None type syntax (3.10), better error messages (3.10+), tomllib (3.11), itertools.batched (3.12), cleaner f-string grammar (3.12) and an improved interactive shell (3.13).
