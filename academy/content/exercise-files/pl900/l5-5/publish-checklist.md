# Publish and channels checklist (Lesson 5.5)

## Before publishing
- [ ] Greeting mentions help desk hours (Lesson 5.2)
- [ ] it-faq.md is added as knowledge and shows as Ready (Lesson 5.3)
- [ ] Create ticket tool has a clear description (Lesson 5.4)
- [ ] Authentication: Authenticate with Microsoft (needed for Teams and Microsoft 365 Copilot)

## Publish
- [ ] Select Publish and wait for the success message. Note the time: ______

## Demo website
- [ ] Channels > Demo website: copy the link. Write your own welcome message and starter phrases:
  - Welcome message: Hi! Ask me about Wi-Fi, printing or passwords.
  - Starter phrases: How do I connect to campus Wi-Fi? / How much does colour printing cost?
- [ ] Open the link in a private window and ask one starter question.
Note: sign-in on the demo website depends on your authentication setting; if it asks you to sign in, use your work account.

## Microsoft Teams
- [ ] Channels > Teams and Microsoft 365 Copilot: turn on the channel, then open the agent in Teams.
- [ ] Ask: How much does colour printing cost? Expected: 5 credits per A4 page.

## Republish test
1. In the Log a ticket topic, change the Message node from
   "Thanks. I have noted:" to "Got it! Ticket details:".
2. Save, but do NOT publish. In Teams, start a new conversation and run the topic.
   Expected: Teams still shows "Thanks. I have noted:".
3. Publish again. In Teams, type "start over" (or start a new chat) and run the topic.
   Expected: Teams now shows "Got it! Ticket details:". It can take a few minutes to update.
