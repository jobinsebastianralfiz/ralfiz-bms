# PL-900 · 5.5 Publish to channels

## Files
- publish-checklist.md

## Steps
1. Download publish-checklist.md and tick the Before publishing items.
2. Publish the agent and note the time.
3. Open Channels > Demo website, set the welcome message and starter phrases from the file, and copy the link.
4. Open the link in a private window (or send it to a friend) and ask one starter question.
5. Turn on the Teams and Microsoft 365 Copilot channel and open the agent in Teams.
6. Ask How much does colour printing cost? in Teams.
7. Do the Republish test: change the message, test in Teams without publishing, then publish and test again.
