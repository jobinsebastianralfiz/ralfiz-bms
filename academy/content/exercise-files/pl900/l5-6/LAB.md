# PL-900 · 5.6 Manage agents: analytics, evaluations and Agent 365

## Files
- test-conversations.md
- evaluation-set.csv
- it-faq-addition.md

## Steps
1. Download the exercise files.
2. Run the 10 conversations in test-conversations.md on the published agent, each as a new conversation.
3. After about an hour, open Analytics. Find the most used topic and the unanswered questions, and write them under Findings.
4. Open Evaluation and create a test set with the 5 questions and expected responses from evaluation-set.csv (upload the file if your version accepts it, or add them one by one). Run it.
5. Note which question scores lowest. It should be the CampusGuest question.
6. Add the paragraph from it-faq-addition.md to it-faq.md, replace the uploaded knowledge file, and publish.
7. Run the evaluation again and compare the two runs.
