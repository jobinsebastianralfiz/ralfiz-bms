# Campus Help Desk: which product fits? (Lesson 1.1)

The college IT team wants a Campus Help Desk. Students report problems, staff fix them and managers track the work.
For each requirement write the ONE product that fits best:
Power Apps, Power Automate, Dataverse, Connectors, Power Pages or Copilot Studio.

| # | Requirement | Product |
|---|---|---|
| 1 | Store every ticket with its category, priority and status, and let only staff see all tickets. | |
| 2 | Help desk agents need a screen to view, triage and update tickets on a laptop or phone. | |
| 3 | When a new ticket arrives, email the agent on duty automatically. | |
| 4 | Parents and visitors without a college account must be able to report a lost-property item on a public website after registering. | |
| 5 | Students ask "How do I connect to campus Wi-Fi?" in Teams at 11 pm and get an answer. | |
| 6 | Every morning at 9:00, send the manager a list of tickets that are past their due date. | |
| 7 | The college already keeps student records in a SQL Server database. Apps and flows must read them. | |
| 8 | The finance team's own REST API holds print-credit balances. Makers want to use it like any other service. | |
| 9 | An agent must be able to log a new ticket for a student during a chat conversation. | |
| 10 | Categories (Network, Hardware, Accounts, Software, Printing, Classroom AV) are linked to many tickets each. | |
