# PL-900 · 3.3 Plan designer

## Files
- business-problem.md

## Steps
1. Download business-problem.md and read the problem statement.
2. On the Power Apps home page, open the plan experience (look for the option to create a solution from a description or plan).
3. Paste the Problem statement section as your description (or attach the file if your version allows documents) and let Copilot draft the plan.
4. Work through the Review checklist: tick each role, user story and component you find in the plan.
5. Fill in the data model table, writing the plan’s table names next to your Ticket, Category and Feedback tables.
6. Edit the status-update requirement as described under Edit to try, and note which parts of the plan change.
7. Saving the plan is optional. If you save it, it goes into a solution with the plan text.

## Check your work
- [ ] The plan lists roles for students and help desk staff, and a manager or equivalent reporting role.
- [ ] Your checklist has a story for each of the 5 numbered needs in the problem statement, or you have noted which one is missing.
- [ ] The plan’s data model includes a ticket table with priority and status, and your comparison table has all 3 rows filled.
- [ ] After your edit, the requirement mentions Teams instead of email.
