# PL-900 · 4.1 Cloud flows and desktop flows

## Files
- flow-types.md

## Steps
1. Download flow-types.md and read the table of flows to build.
2. Build flow 1, CHD - New ticket log, as an automated cloud flow with the Dataverse trigger shown, add the Compose action and save.
3. Add the test ticket Flow test - lab 4.1 to Ticket, then open the flow’s run history.
4. Build flow 2, CHD - Say hello, as an instant cloud flow and run it from the portal or the Power Automate mobile app.
5. Build flow 3, CHD - Daily 9 am check, as a scheduled cloud flow with the Recurrence settings shown.
6. On a Windows PC, install Power Automate for desktop and build Hello Notepad: Run application notepad.exe, then Send keys Hello. Run it.
7. Classify the 6 scenarios at the end of flow-types.md and check the answer key.

## Check your work
- [ ] CHD - New ticket log has 1 succeeded run, and its Compose output shows Flow test - lab 4.1.
- [ ] CHD - Say hello shows a succeeded run and you received the notification or email.
- [ ] CHD - Daily 9 am check shows its next run at 9:00 in your time zone.
- [ ] Hello Notepad opens Notepad and the word Hello appears in it.
- [ ] Your 6 scenario answers match the key: Scheduled, Automated, Instant, Desktop (unattended), Desktop (attended), Automated.
