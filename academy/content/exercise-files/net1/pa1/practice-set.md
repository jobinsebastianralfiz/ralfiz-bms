# Practice set 1.1: Teaching: concepts, objectives and levels

Time yourself: problems 1–8 in 8 minutes, problems 9–15 in 8 minutes. Every question has four options; choose one.

**1.** Which pair is correctly matched?
(1) Memory level – Morrison  (2) Understanding level – Hunt  (3) Reflective level – Hunt  (4) Memory level – Jackson

**3.** “The student will compare the use of arrays and linked lists for a music playlist.” The main level (revised taxonomy) is:
(1) Remember  (2) Understand  (3) Create  (4) Evaluate

| B. Understanding | II. Recall and recognition items |
| C. Reflective | III. Items asking for explanation and application |
