# Practice set 2.2: Data representation

Time yourself: problems 1–8 in 12 minutes, problems 9–15 in 12 minutes. Every question has four options; choose one.

**1.** (156.8125)₁₀ in hexadecimal is:
(1) 9C.D  (2) 9C.C  (3) 9B.D  (4) 234.64

**2.** If (132)_b = (42)₁₀, the base b is:
(1) 4  (2) 5  (3) 6  (4) 7

**3.** Using 10’s complement arithmetic, 3175 − 6428 is computed as 3175 + 3572 = 6747. The final answer is:
(1) +6747  (2) −6747  (3) −3253  (4) +3253

**4.** In 8-bit 2’s complement, 01101110 + 00110011 gives the bit pattern and overflow flag:
(1) 10100001, V = 0  (2) 10100001, V = 1  (3) 00100001, V = 1  (4) 10100000, V = 1

**5.** The IEEE 754 single-precision pattern C2F00000 (hex) represents:
(1) −60.0  (2) −120.0  (3) −240.0  (4) 120.0

**6.** The IEEE 754 single-precision representation of 85.125 is:
(1) 42AA4000  (2) 42AA2000  (3) 422A4000  (4) 43AA4000

**7.** The IEEE 754 single-precision pattern 00400000 (hex) represents:
(1) 2^−126  (2) 2^−127  (3) 2^−128  (4) 0.5 × 2^−127

**8.** Data 1101 is encoded with the Hamming (7,4) code, even parity, check bits at positions 1, 2, 4 and data at 3, 5, 6, 7. The code word (positions 1 to 7) is:
(1) 1010101  (2) 0110101  (3) 1011010  (4) 1010110

**9.** A single-error-correcting Hamming code for 32 data bits needs how many check bits, and what is the code-word length?
(1) 5 and 37  (2) 6 and 38  (3) 6 and 37  (4) 7 and 39

**10.** Match List I (representation of −5 in 4 bits) with List II (bit pattern).

| List I | List II |
|---|---|
| A. Sign-magnitude | I. 1011 |
| B. 1’s complement | II. 0011 |
| C. 2’s complement | III. 1101 |
| D. Excess-8 | IV. 1010 |

(1) A-III, B-IV, C-I, D-II  (2) A-IV, B-III, C-I, D-II  (3) A-III, B-I, C-IV, D-II  (4) A-III, B-IV, C-II, D-I

**11.** Assertion (A): Sign-extending a 2’s complement number to more bits does not change its value.
Reason (R): Copying the sign bit into the new high-order positions adds bits whose weights cancel out with the change in the weight of the old sign bit.
(1) Both (A) and (R) are true and (R) is the correct explanation of (A)
(2) Both (A) and (R) are true but (R) is NOT the correct explanation of (A)
(3) (A) is true but (R) is false
(4) (A) is false but (R) is true

**12.** Statement I: ASCII is a 7-bit code defining 128 characters.
Statement II: EBCDIC is an 8-bit character code associated with IBM mainframes.
(1) Both Statement I and Statement II are true
(2) Both Statement I and Statement II are false
(3) Statement I is true but Statement II is false
(4) Statement I is false but Statement II is true

**13.** Which of the following are weighted codes?

(1) A, B and E only  (2) A, B, C and E only  (3) A and B only  (4) A, B, D and E only
