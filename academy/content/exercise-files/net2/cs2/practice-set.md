# Practice set 1.2: Sets, relations and functions

Time yourself: problems 1–8 in 12 minutes, problems 9–15 in 12 minutes. Every question has four options; choose one.

**1.** The number of relations on a set with 4 elements is:
(1) 256  (2) 4096  (3) 65536  (4) 16

**2.** The number of symmetric relations on a set with 4 elements is:
(1) 64  (2) 1024  (3) 4096  (4) 256

**3.** The number of onto functions from a 6-element set to a 3-element set is:
(1) 729  (2) 540  (3) 90  (4) 120

**4.** The number of injective functions from a 4-element set to a 6-element set is:
(1) 360  (2) 1296  (3) 15  (4) 720

**5.** The number of equivalence relations on a 5-element set is:
(1) 15  (2) 25  (3) 52  (4) 203

**6.** In how many ways can a 6-element set be partitioned into exactly 3 non-empty blocks?
(1) 90  (2) 65  (3) 540  (4) 20

**7.** R = {(1, 2), (2, 3), (3, 1)} on {1, 2, 3}. The number of ordered pairs in the transitive closure of R is:
(1) 3  (2) 6  (3) 9  (4) 7

**8.** Match List I (poset) with List II (description).

| List I | List II |
|---|---|
| A. D30 under divisibility | I. A chain (total order) |
| B. D12 under divisibility | II. A Boolean algebra with 8 elements |
| C. (P({a, b}), ⊆) | III. A lattice that is distributive but not complemented, and not a chain |
| D. {1, 2, 4, 8} under divisibility | IV. A Boolean algebra with 4 elements |

(1) A-II, B-III, C-IV, D-I  (2) A-II, B-I, C-IV, D-III  (3) A-IV, B-III, C-II, D-I  (4) A-II, B-IV, C-III, D-I

**9.** The number of edges in the Hasse diagram of (D72, |) is:
(1) 12  (2) 16  (3) 17  (4) 18

**10.** Assertion (A): The lattice (D36, |) is not complemented.
Reason (R): 36 is not square-free, and 6 has no complement in D36.
(1) Both (A) and (R) are true and (R) is the correct explanation of (A)
(2) Both (A) and (R) are true but (R) is NOT the correct explanation of (A)
(3) (A) is true but (R) is false
(4) (A) is false but (R) is true

**11.** Let f(x) = 2x + 1 and g(x) = x² on ℝ. The value of (f ∘ g)(3) − (g ∘ f)(1) is:
(1) 10  (2) 0  (3) 28  (4) −10

**12.** R = {(1, 1), (2, 2), (3, 3), (1, 2), (2, 1)} on {1, 2, 3}. Which statements are correct?
A. R is reflexive  B. R is symmetric  C. R is antisymmetric  D. R is transitive  E. R is an equivalence relation with 2 classes
(1) A, B, D and E only  (2) A, B and D only  (3) A, B, C, D and E  (4) B, D and E only

**13.** The number of antisymmetric relations on a set with 4 elements is:
(1) 11664  (2) 4096  (3) 729  (4) 59049

**14.** The number of commutative binary operations on a set with 3 elements is:
(1) 19683  (2) 729  (3) 27  (4) 6561

**15.** Statement I: Every finite non-empty poset has at least one minimal element.
Statement II: Every finite non-empty lattice has a greatest element and a least element.
(1) Both Statement I and Statement II are true  (2) Both Statement I and Statement II are false  (3) Statement I is true but Statement II is false  (4) Statement I is false but Statement II is true
