# Practice set: Transformations, 3D and curves (UGC NET Paper 2, Unit 3)

Time: 22 minutes. Column vectors are used (P′ = M·P), and positive angles are anticlockwise.

**1.** Rotate the point (4, 3) by 90° about the pivot (2, 2). Give the composite matrix and the image.

**2.** Write the matrix for scaling by sₓ = 2, s_y = 3 about (1, 1) and apply it to the rectangle (1, 1), (3, 1), (3, 2), (1, 2).

**3.** Reflect (3, 1) about the line y = x + 2. Give the simplified composite matrix.

**4.** Apply an x-shear with shₓ = 2 to the unit square. List the new corners and the new area.

**5.** A triangle with vertices (0, 0), (4, 0), (0, 3) is scaled by sₓ = 2, s_y = 2 and then rotated by 45°. What is the new area?

**6.** Where does (1, 0) go under R(90°)·T(3, 0)? Under T(3, 0)·R(90°)?

**7.** Rotate (1, 0, 0) by 90° about the y-axis, and (0, 1, 0) by 90° about the x-axis.

**8.** Project (6, 4, 12) in perspective (COP at the origin) onto the plane z = 3. Also give the orthographic projection onto the same plane.

**9.** For the cubic Bezier curve with control points (0, 0), (2, 4), (6, 4), (8, 0), find the points at t = 1/2 and t = 1/4, and the tangent vector at t = 0.

**10.** Match List I with List II.

| List I | List II |
|---|---|
| A. Bezier curve | I. Local control; degree independent of the number of points |
| B. B-spline | II. Passes through the end points; global control |
| C. Gouraud shading | III. Interpolates normal vectors |
| D. Phong shading | IV. Interpolates vertex intensities |

(1) A-II, B-I, C-IV, D-III  (2) A-I, B-II, C-IV, D-III  (3) A-II, B-I, C-III, D-IV  (4) A-II, B-IV, C-I, D-III

**11.** A cubic uniform B-spline has 10 control points. How many knot values and how many segments does it have?

**12.** A pixel's depth-buffer entry starts at 1.0 (smaller = nearer). Polygons arrive with depths 0.9 (yellow), 0.3 (red), 0.5 (green). What colour is shown? What would the painter's algorithm draw last?

**13.** Convert RGB (0.2, 0.4, 0.6) to CMY and to CMYK, and give V and S of this colour in HSV.

**14.** Assertion (A): The inverse of a rotation matrix can be found without any division. Reason (R): A rotation matrix is orthogonal, so its inverse equals its transpose.

**15.** How much memory do a 1024 × 768 depth buffer (24 bits per entry) and a 1024 × 768 refresh buffer (24 bits per pixel) need together?
