# Practice set 1.6: Graph theory

Time yourself: problems 1–8 in 12 minutes, problems 9–15 in 12 minutes. Every question has four options; choose one.

**1.** A simple graph has 35 edges. Four vertices have degree 5, five vertices have degree 4, and every other vertex has degree 3. The number of vertices is:
(1) 17  (2) 19  (3) 20  (4) 10

**2.** A connected planar simple graph has 20 vertices, each of degree 3. The number of faces (including the outer face) is:
(1) 10  (2) 11  (3) 12  (4) 30

**3.** The number of spanning trees of K₆ is:
(1) 720  (2) 1296  (3) 216  (4) 7776

**4.** The chromatic number of the wheel formed by an 11-cycle and a hub adjacent to all 11 cycle vertices is:
(1) 2  (2) 3  (3) 4  (4) 12

**5.** The maximum number of edges in a simple graph with 12 vertices and 4 components is:
(1) 36  (2) 45  (3) 28  (4) 66

**6.** A connected graph has vertex degrees 4, 3, 3, 2, 2, 2. Which statement is true?
(1) It has an Euler circuit  (2) It has an Euler path but no Euler circuit  (3) It has neither an Euler path nor an Euler circuit  (4) It must be Hamiltonian

**7.** The number of edges of the hypercube Q₅ is:
(1) 32  (2) 64  (3) 80  (4) 160

**8.** The number of distinct Hamiltonian cycles in K₇ (a cycle and its reverse counted once) is:
(1) 720  (2) 5040  (3) 2520  (4) 360

**9.** The number of proper colourings of the path P₄ (4 vertices) using at most 3 colours is:
(1) 24  (2) 18  (3) 81  (4) 12

**10.** Match List I (graph) with List II (number of spanning trees).

| List I | List II |
|---|---|
| A. K₄ | I. 7 |
| B. C₇ | II. 125 |
| C. K₂,₄ | III. 16 |
| D. K₅ | IV. 32 |

(1) A-III, B-I, C-IV, D-II  (2) A-III, B-IV, C-I, D-II  (3) A-IV, B-I, C-III, D-II  (4) A-III, B-I, C-II, D-IV

**11.** Assertion (A): The cube graph Q₃ has no Euler circuit.
Reason (R): Every vertex of Q₃ has odd degree 3.
(1) Both (A) and (R) are true and (R) is the correct explanation of (A)
(2) Both (A) and (R) are true but (R) is NOT the correct explanation of (A)
(3) (A) is true but (R) is false
(4) (A) is false but (R) is true

**12.** Statement I: Every simple planar graph with v ≥ 3 vertices satisfies e ≤ 3v − 6.
Statement II: Every simple graph with v ≥ 3 vertices satisfying e ≤ 3v − 6 is planar.
(1) Both Statement I and Statement II are true
(2) Both Statement I and Statement II are false
(3) Statement I is true but Statement II is false
(4) Statement I is false but Statement II is true

**13.** Which of the following are true for every tree T with n ≥ 2 vertices?
A. T has n − 1 edges
B. There is a unique path between any two vertices
C. Adding any new edge creates exactly one cycle
D. Removing any edge disconnects T
E. χ(T) = 3
(1) A, B and C only  (2) A, B, C and D only  (3) A, B, C, D and E  (4) B, C and D only
